# Bitcoin Merchant Stickers (with QR Code)

## Overview
These stickers are designed for merchants who accept Bitcoin payments. Each sticker includes a QR code for easy scanning, providing customers with a convenient way to make transactions.

## Dimensions
- **Sticker Size:** 40 cm (width) × 22 cm (height)  
- **QR Code Size:** 10 cm (width) × 10 cm (height)  

## Notes
- The QR code should be placed in a visible position on the sticker.  
- Ensure the QR code maintains high contrast (dark foreground on light background) for reliable scanning.  
- Stickers are intended for placement on store windows, doors, or counters.
